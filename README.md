# Facial Emotion Recognition using KNN in R

## Project Overview
This project implements a Facial Emotion Recognition (FER) system using the K-Nearest Neighbours (KNN) algorithm in R.
 This classifies facial expressions into emotion categories using image preprocessing and machine learning techniques.

## Dataset
This project uses the JAFFE facial expression dataset.

The dataset contains 7 facial images representing emotions such as:
Anger, Disgust,Fear, Happy, Neutral, Sad, Surprise

## Technologies Used
 R, EBImage, caret, class, ggplot2

## Methodology
1. Load TIFF facial images
2. Resize images to 64×64 pixels
3. Convert images to grayscale
4. Flatten images into feature vectors
5. Split dataset into training and testing sets
6. Train KNN classifier
7. Evaluate using confusion matrix and accuracy

## Results
- KNN classification was evaluated for different K values.
- Accuracy and confusion matrices were generated.
- Visualization of Accuracy vs K was created using ggplot2.
